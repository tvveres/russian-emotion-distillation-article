# Классификация эмоций в русскоязычных отзывах: LLM → ruBERT

[![Build](https://github.com/tvveres/russian-emotion-distillation-article/actions/workflows/build.yml/badge.svg)](https://github.com/tvveres/russian-emotion-distillation-article/actions)

**Автор:** Верещагина Татьяна Владимировна  
**Группа:** БПМ-23-ПО-3, НИТУ «МИСИС»  
**Дисциплина:** Научное письмо, ПЗ-3

## Тема статьи

Сравнительное исследование и дистилляция больших языковых моделей для классификации эмоций в русскоязычных отзывах пользователей интернет-сервисов.

## Что подготовлено

Статья содержит введение, анализ работ, постановку задачи, описание методов и список литературы. Это проект исследования: обучение и эксперименты ещё не выполнены, результаты не заявляются. По условию ПЗ-3 разделы с экспериментом и заключением могут отсутствовать.

Идея: LLM размечает отзывы по пяти эмоциям, после чего компактная модель на основе ruBERT обучается на этих метках и ручной разметке CEDR. Сравнение планируется с TF-IDF + логистической регрессией, обычным ruBERT и прямым использованием LLM.

- `LICENSE`, `CHANGELOG.md` — лицензия и история исходного шаблона.

## Как скачать PDF

1. Открыть [Actions](https://github.com/tvveres/russian-emotion-distillation-article/actions).
2. Выбрать последний успешный запуск **Build**.
3. В разделе **Artifacts** скачать `article.pdf` (авторская статья).

После изменения `article.tex` и коммита PDF пересобирается автоматически. На первом запуске форка GitHub может потребовать включить Actions.

Локальная сборка с установленным Tectonic:

```bash
make article
```

Результат: `build/article.pdf`. CI использует Windows с Times New Roman и Courier New, как исходный шаблон.

## Данные и ограничения

- [CEDR](https://github.com/sag111/CEDR): пять эмоций; отсутствие эмоций кодируется пустым набором меток.
- [RuReviews](https://github.com/sismetanin/rureviews): товарные отзывы с тональностью; эмоциональные метки требуется создать отдельно.

Товарные отзывы не охватывают все интернет-сервисы. Для обобщения на сервисные отзывы нужны отдельные данные. Сырые данные и веса моделей в этот репозиторий не загружены. Собственная разметка пока только запланирована. Проверять права и условия распространения данных следует до публикации производного корпуса.
