# Пилот переноса эмоциональной разметки на реальных отзывах RuReviews

Воспроизводимый локальный эксперимент: Qwen3-0.6B (4-bit MLX) размечает 480 реальных отзывов, классификаторы обучаются воспроизводить её метки.

**Метрики показывают согласие с LLM, а не точность распознавания человеческих эмоций. Независимой ручной эмоциональной разметки в этом эксперименте нет.** Исходная тональность RuReviews не заменяет эмоциональные категории.

## Данные

Источник: https://github.com/sismetanin/rureviews, коммит `2f6e61d30dc6c58ba47dce72e5803e1f0a3f38a7`. Файл `women-clothing-accessories.3-class.balanced.csv`, лицензия Apache-2.0.

Удалены пустые строки и точные повторы после приведения к нижнему регистру и схлопывания пробелов. Используются тексты длиной 30–500 символов; корпус не репрезентирует все отзывы и сервисы. Отобрано по 160 отзывов из каждого исходного класса тональности, seed 42. Опечатка исходного класса `neautral` нормализована в `neutral`.

Разбиение выполнено до получения псевдометок: 320 train, 80 validation, 80 test. Идентификаторы — 0-based индексы строк, прочитанных pandas из исходного TSV (без строки заголовка). Файл `results/sample.json` фиксирует весь отбор.

## Запуск

Python 3.13; для локальной LLM нужен Apple Silicon / MLX. Нужны свободное место и загрузка открытых весов с Hugging Face. Данные не отправляются во внешний LLM API.

```bash
python3.13 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python download_data.py
.venv/bin/python -u run.py
.venv/bin/python analyze.py
.venv/bin/python make_figures.py
.venv/bin/python verify.py
```

`run.py` продолжает разметку по сохранённому журналу, если запуск прервался. Для полного повторного прогона используйте новую папку без старых `results/teacher.jsonl` и `results/sample.json`. Скачивание моделей кэшируется в `cache/`.

## Модели и протокол

- Учитель: `mlx-community/Qwen3-0.6B-4bit`, revision `73e3e38d981303bc594367cd910ea6eb48349da8`; greedy decoding, thinking выключен, максимум 48 выходных токенов. Это компактная локальная генеративная модель, не проверка всех современных LLM.
- Словесный TF-IDF: n-grams 1–2, `min_df=2`, sublinear TF.
- Символьный TF-IDF: n-grams 3–5, `min_df=2`, sublinear TF.
- Замороженный `cointegrated/rubert-tiny2`, revision `e8ed3b0c8bbf4fb6984c3de043bf7d2f4e5969ae`: нормализованный CLS-вектор, максимум 256 токенов, batch 16. Энкодер **не дообучается**.
- Во всех трёх учениках: OneVsRest + LogisticRegression(C=1, class_weight='balanced', max_iter=2000).
- Один общий порог на пять эмоций выбирается по macro-F1 на validation из 0.1–0.9. Тест для настройки не используется.
- Некорректный JSON, неизвестные категории и обрезанные ответы записываются как ошибки формата. Основные метрики согласия считаются только для отзывов с корректным ответом учителя; количество исключённых отзывов указывается отдельно.
- Пустой список — отсутствие пяти выбранных эмоций, отдельный шестой классификатор не используется.
- Единственный seed и небольшая выборка: вывод о превосходстве архитектуры в целом не делается. Bootstrap отражает только неопределённость тестовых объектов при фиксированных моделях и фиксированных псевдометках.

## Проверяемые материалы

`results/protocol.json` — инструкция и конфигурация; `teacher.jsonl` — необработанные ответы и замеры; `sample.json` — отзывы и разбиение; `metrics.json` — результаты учеников; `label_audit.json` — распределение меток; `test_predictions.json` — ответы на тесте; `analysis.json` — контрольные показатели и замеры.

Исходные данные и веса не включаются в репозиторий. Производная выборка из 480 отзывов сохранена с указанием источника и исходной лицензии. Тексты отзывов — цитаты из корпуса; орфография не исправлялась.

Замеры TF-IDF и ruBERT выполнены на CPU (PyTorch: 4 потока), Qwen — на MLX / Metal. Задержки относятся к этим конфигурациям, а не к одинаковому вычислителю.

Файлы `results/` содержат опубликованный прогон. `verify.py` проверяет его без загрузки моделей. Полная перегенерация может дать отличия при другой версии Metal или оборудования; сырые ответы сохранены для проверки опубликованных чисел.
